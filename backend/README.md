# District Badges backend

The backend provides the staff interface and REST API for managing a district badge shop. It covers the badge catalogue, stock, group orders, fulfilment, replenishments, invoices and staff users.

For requirements, local setup, configuration, API details and the domain model, see the [backend development guide](../docs/backend-development.md). For the Kubernetes installation and operations guide, see [deployment](../docs/deployment/kubernetes.md).

The stock ledger model is described in [stock transactions](../docs/backend/stock-transactions.md).
